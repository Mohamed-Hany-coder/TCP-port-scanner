# Project Plan

This repository follows the 10-person team plan prepared for the system-programming course.

- Project manager/integration: Member 1
- Architecture: Member 2
- CLI: Member 3
- Port parser: Member 4
- TCP engine: Member 5
- Concurrency: Member 6
- Output: Member 7
- Testing: Member 8
- Documentation/UX: Member 9
- DevOps/release: Member 10

Recommended Jira workflow:

`Backlog -> To Do -> In Progress -> Code Review -> Testing -> Done`

Definition of Done: implementation merged, reviewed, formatted, vetted, tested normally and with the race detector, documented, and passing CI.
