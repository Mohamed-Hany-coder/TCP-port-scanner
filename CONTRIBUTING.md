# Contributing

1. Create a branch named `feature/TPS-123-description` or `fix/TPS-123-description`.
2. Keep changes focused and include tests.
3. Run `gofmt -w .`, `go vet ./...`, `go test ./...`, and `go test -race ./...`.
4. Update README or the project report when user-visible behavior changes.
5. Open a pull request with the Jira key in the title.
6. Request review from a teammate and merge only after CI passes.

Only scan hosts that you own or are explicitly authorized to test.
